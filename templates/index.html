ℹ️ About

This tool converts Garmin FIT (Flexible and Interchange Protocol) files to tabular CSV and JSON formats for analysis.

Output Files:

  • records.csv - Second-by-second data (power, heart rate, speed, distance, etc.)
  • laps.csv - Lap summary data
  • session.json - Session metadata and totals
  • events.csv - Event markers (pauses, auto-pauses, etc.)

Features:

  • Preserves raw data without smoothing or interpolation
  • Correct unit conversion (distance, temperature, speed)
  • Automatic validation of data consistency
  • Batch processing support
  • FIT checksum verification (optional)
